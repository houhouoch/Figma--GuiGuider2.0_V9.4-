# Validation evidence / 验证证据

The `v9` directory contains the controlled-sync reports used to review and promote the GUI Guider project.

`v9` 目录保存本次 GUI Guider 受控同步、审核和晋升所使用的验证报告。

Large transient screenshots, GUI Guider tool binaries, simulator builds, and local caches are intentionally excluded.

大型临时截图、GUI Guider 工具文件、模拟器构建产物和本机缓存未纳入仓库。

# Security / 安全

## 中文

请不要在公开 Issue 中提交 Figma Token、MCP 凭据、GitHub Token、私有设计链接或未脱敏的客户数据。安全问题请通过 GitHub 的私密漏洞报告功能联系仓库维护者。

本仓库不会收集凭据。所有访问 Figma、GitHub 或本地 GUI Guider 的授权都应由使用者在自己的环境中配置。

## English

Do not post Figma tokens, MCP credentials, GitHub tokens, private design links, or unredacted customer data in public issues. Use GitHub private vulnerability reporting to contact the maintainer.

The repository does not collect credentials. Figma, GitHub, and local GUI Guider authorization must be configured by each user in their own environment.

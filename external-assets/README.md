# External source assets / 外部源素材

The reviewed GUI Guider project images are included under `project/resources/image`.

经过审核的 GUI Guider 项目图片已保存在 `project/resources/image`。

Some historical conversion scripts can optionally rebuild those images from the original artwork. That source artwork is not redistributed. Place an authorized local copy under:

部分历史转换脚本可以从原始素材重新生成图片。原始素材不在本仓库中再分发；如拥有授权副本，请放到：

```text
external-assets/source/
```

or set / 或设置：

```text
FIGMA_GUI_GUIDER_ASSET_ROOT
```

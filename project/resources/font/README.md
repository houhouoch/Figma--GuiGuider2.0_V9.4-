# External font / 外部字体

The GUI Guider project uses Alibaba PuHuiTi 2.0 Regular. The font binary is not redistributed in this repository.

本工程使用阿里巴巴普惠体 2.0 Regular。仓库不直接再分发字体二进制。

Download it from the [official Alibaba Design page](https://done.alibabadesign.com/puhuiti2.0), then run:

请从[阿里巴巴设计官方页面](https://done.alibabadesign.com/puhuiti2.0)下载，然后运行：

```powershell
python tools/prepare_local_project.py --font "D:\path\to\AlibabaPuHuiTi2.ttf"
```

Required destination basename / 工程要求的目标文件名：

```text
AlibabaPuHuiTi2.ttf
```

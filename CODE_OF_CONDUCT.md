# Code of Conduct / 行为准则

Be respectful, specific, and evidence-driven. Report technical disagreements with reproducible inputs and results. Harassment, personal attacks, and publication of private credentials or customer data are not accepted.

请保持尊重、具体并以证据为基础。技术分歧应附可复现输入与结果。禁止骚扰、人身攻击，以及公开私人凭据或客户数据。

# GUI Guider 审核工程必须包含完整字体与图片资源闭包

## 结论

独立 GUI Guider 审核工程不仅要复制显式图片路径，还必须复制并注册 `text_family` 引用的字体。缺失字体会触发回退字体，使字号、字宽、行高、基线、裁剪和坐标审核全部失效。

## 复现现象

审核工程缺少自定义字体时会出现：

- 缺字；
- 字号不正确；
- 基线偏移；
- 文本框裁剪；
- 原本正确的坐标看起来错位。

## 根本原因

`text_family` 往往只保存字体文件名，不包含 `resources/font/...` 完整路径。只扫描显式资源路径会漏掉字体。

## 正确做法

1. 扫描所有 `text_family`。
2. 在审核目录复制对应 `.ttf/.otf`。
3. 确认 GUI Guider 已注册该字体。
4. 再比较字体、字号、位置、尺寸、基线和裁剪。

## 已验证证据

UDP3900 项目补齐字体后：

- 664 个 Figma 文本节点完成映射；
- 647 个既有 Label 保持字体和字号；
- 字体映射错误为 0；
- 字号映射错误为 0；
- 缺失字体文件为 0；
- 用户确认显示恢复正常。

## 禁止做法

字体回退时不要通过移动 Label 或扩大文本框来掩盖问题。

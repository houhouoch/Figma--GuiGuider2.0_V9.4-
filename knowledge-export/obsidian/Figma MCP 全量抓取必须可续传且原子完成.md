# Figma MCP 全量抓取必须可续传且原子完成

## 结论

全量 Figma 抓取必须支持分块续传，并且只能在根节点、分片和节点总数全部校验后发布 Manifest。限流或超时产生的半成品目录不能作为转换输入。

## 必须校验

- 预期根节点数量；
- 每个根的 `start/total`；
- 分片起点连续；
- 合并节点数等于报告总数；
- Figma ID 唯一；
- 页面截图和结构文件 SHA-256；
- 最终完成标志最后写入。

## 已验证故障

一次 31 页全量抓取中，本地 MCP 只完整返回 18 页，4 个大页面超时，其余页面限流。远程整页响应又发生截断。

最终改用远程分块抓取并校验后，获得：

- 31 个页面；
- 1756 个节点；
- 节点 ID 无重复；
- 分片连续；
- 完整 Manifest。

## 防错规则

- 限流后不要持续重试同一个接口。
- 不要接受截断的整页响应。
- 不完整版本应保留为诊断证据，但不得进入候选生成。
